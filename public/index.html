whistle.sse-viewer 配置

配置保存在本机浏览器的 localStorage（键名 whistle.sse-viewer.config）， 仅影响当前浏览器的 Whistle 界面；保存后 SSE Tab 立即生效，无需重启 Whistle，也无需修改 package.json。
预览字符数previewLimit
内容区最多展示多少字符。填 -1 表示不裁剪，直接显示完整内容。
字符
预览区取哪一段previewMode
内容超长时展示哪一段：尾部适合流式场景（最新内容优先），头部适合看开头。
结尾补空行trailingSeparator
Whistle 拆分帧时会去掉 \n\n 分隔符，本插件用 \n\n 重新拼接。
若原始流以 \n\n 结尾，选择 补 可与原始字节完全一致。
data 内容 JSON 格式化formatJson
开启后会尝试把 data: 后的 JSON 内容格式化成多行，便于阅读；解析失败（如 data: [DONE]）或不是 JSON 时保持原样。
预览、View All、Copy All 均使用格式化后的内容；需要原始可回放的 SSE 文本时请关闭本项。
